# CLAUDE.md

Guidance for working in this repository.

## What this is

**Pathways USA** — a React SPA that helps immigrants prepare for the U.S. naturalization
test (civics questions, reading/writing dictation, vocabulary, mock interview, lessons),
with a student/tutor classroom layer and an admin content tool. It is a **Base44** app:
there is no custom backend in this repo. All data, auth, email, LLM calls and file
uploads go through the `@base44/sdk` client against the Base44 platform.

Stack: React 18, Vite 6 (`@base44/vite-plugin`), react-router-dom 6, TanStack Query
(provider only — data fetching is mostly hand-rolled `useEffect` + `useState`),
Tailwind + shadcn/ui (Radix), framer-motion, recharts, lucide-react.

## Repo layout — important caveat

This repo is a **flattened export** of a Base44 project (committed via "Add files via
upload"). The code still imports as if it lived under `src/` with a `pages/` folder:

- `pages.config.js` imports `./pages/Admin`, `./pages/Dashboard`, … but the page files
  sit at the repo root (`Admin.jsx`, `Dashboard.jsx`, …).
- `jsconfig.json` maps `@/*` → `./src/*`; `eslint.config.js` and `index.html`
  (`/src/main.jsx`) also assume `src/`.
- There is no `vite.config.js` (the Base44 platform provides it).

So `npm run dev` / `build` will not work as-is. To run locally, recreate the layout:
move everything except `base44/`, `dist/`, `index.html`, and root configs into `src/`,
put the page files in `src/pages/`, and add a `vite.config.js` using
`@base44/vite-plugin` with the `@` → `src` alias. `dist/` is a stale build artifact.

```
App.jsx, main.jsx, Layout.jsx, pages.config.js   app shell / routing
Admin, Dashboard, Home, Lessons, Practice,        pages (belong in pages/)
Profile, Progress, StudyHistory, Tutor .jsx
Messages.jsx                                      EMPTY (0 bytes), not routed
OAuthConsent.jsx                                  MCP OAuth consent page, not in pages.config
api/        base44Client.js, entities.js, integrations.js
lib/        AuthContext, NavigationTracker, app-params, query-client, PageNotFound, VisualEditAgent
hooks/      useContentManager (generic admin CRUD), useLessonTranslation, use-mobile
components/ feature folders + components/ui (shadcn, don't hand-edit)
utils/      createPageUrl(pageName) -> "/PageName"
base44/     config.jsonc (app name/build) + entities/*.jsonc (18 schemas)
```

Commands (`package.json`): `npm run dev`, `build`, `lint`, `lint:fix`, `typecheck`,
`preview`. No test suite.

## Architecture

**Boot** — `main.jsx` → `App.jsx`: `AuthProvider` → `QueryClientProvider` → `Router`
→ `NavigationTracker` + `AuthenticatedApp`, plus `Toaster` and `VisualEditAgent`
(Base44 editor iframe integration; leave alone).

**Config / auth params** — `lib/app-params.js` reads `app_id`, `server_url`,
`access_token`, `from_url`, `functions_version` from the URL query string, falling back
to `VITE_BASE44_APP_ID` / `VITE_BASE44_BACKEND_URL` and to `localStorage`
(`base44_*` keys). `access_token` is stripped from the URL after being read;
`?clear_access_token=true` wipes the stored token.

**Auth gate** — `lib/AuthContext.jsx` first fetches the app's public settings with a raw
SDK axios client (`/api/apps/public/prod/public-settings/by-id/:appId`), then calls
`base44.auth.me()` if a token exists. 403 reasons map to `auth_required` (auto redirect
to login) or `user_not_registered` (renders `UserNotRegisteredError`). The client is
created with `requiresAuth: false`, so most pages also render for signed-out visitors
and individually call `base44.auth.me().catch(() => null)`.

**Routing** — `pages.config.js` is auto-generated by Base44 (only `mainPage` is meant
to be edited; it is `"Home"`). Each key becomes route `/<Key>`; `/` renders the main
page. Every page is wrapped in `Layout.jsx`. Link with `createPageUrl('Practice')`.

**Layout / roles** — `Layout.jsx` is the real session orchestrator:
- loads the user and their `PublicProfile`(s); deletes duplicate profiles, keeping the
  one with `account_type`; caches role in `localStorage` as `role_<email>`;
- if no `account_type`, shows `onboarding/RoleSelectionDialog` (student vs tutor);
- handles `?tutor_invite=<tutorEmail>` (persisted as `pending_tutor_invite`) by creating
  or activating a `TutorRelationship` for students;
- builds nav by role: tutors get *Tutor Portal*; students get Practice / Lessons /
  Progress / My Classroom; `user.role === 'admin'` adds *Admin*.

Two notions of "role": the app role is `PublicProfile.account_type`
(`student`/`tutor`); the platform role is `User.role` (`admin`/`user`) from
`base44.auth.me()`. Admin gating is client-side only (`Admin.jsx` denies only when a
user is loaded and not admin — a signed-out visitor sees the page shell; real
protection must come from Base44 entity permissions).

**Pages**
- `Home` — marketing landing.
- `Dashboard` — lesson overview + `LessonProgress` status cards.
- `Lessons` — lesson list by topic, `LessonDetail` (content, flashcards, oral quiz
  graded by LLM, notes, translation via `useLessonTranslation`), recommendations.
- `Practice` — core study loop: dictation (`Sentence`), vocabulary, civics test
  (`CivicsQuestion`, 2008 vs 2025 version), reading aloud (`ReadingSentence`, seeded
  on first use), interview (`InterviewQuestion`), matching/flashcard games, tutor
  assignments. Writes `UserProgress` with SM-2 spaced-repetition fields, completes
  `Assignment`s, notifies tutors, awards `points` via `auth.updateMe`.
- `Progress` — mastery stats, charts, practice calendar, test-date tracker, leaderboard.
- `Tutor` — `TutorDashboard`/`MyStudents` for tutors, `MyTutor` for students.
- `Profile` — display name, `PublicProfile`, badges, representative finder.
- `StudyHistory` — past `AIStudyLog` Q&A from the AI Study Buddy.
- `Admin` — CRUD tabs for Sentence / VocabularyWord / CivicsQuestion via
  `useContentManager`, plus `GenerateLessonsButton` (LLM-generates `Lesson`,
  `LessonFlashcard`, `LessonQuiz` from civics questions).

**Conventions / gotchas**
- Entities link by **email strings**, not user IDs (`user_email`, `tutor_email`,
  `student_email`, …). Emails are normalized with `.toLowerCase().trim()` in most
  places — keep doing that on reads and writes.
- No server-side joins: code fetches whole lists (`list()` / `filter(..., 1000)`) and
  joins/aggregates in the browser (e.g. `StudentProgressReport`, `Progress`).
- `User` is a Base44 built-in: regular users can only read/update themselves (via
  `base44.auth.me()` / `updateMe()`), which is why `PublicProfile` exists as a
  world-readable mirror (leaderboard, tutor lookup by `invite_code`).
- Base44 adds `id`, `created_date`, `updated_date`, `created_by` to every record;
  sort strings like `'-created_date'` rely on these.
- Do not modify the `fetch` calls / `ctx` handling in `OAuthConsent.jsx` (see its header
  comment); styling and copy are safe to change.

## Entities (`base44/entities/*.jsonc`)

`*` = required. Platform fields (`id`, `created_date`, `updated_date`, `created_by`)
are implicit on all entities.

### Content (admin-managed / seeded)

**Sentence** — dictation sentences
- `text`* string
- `category` enum `Civics | History | Government | Geography | Holidays` (default `Civics`)
- `difficulty` enum `easy | medium | hard` (default `easy`)

**ReadingSentence** — read-aloud sentences
- `text`* string
- `difficulty` enum `easy | medium | hard` (default `easy`)

**VocabularyWord**
- `word`* string
- `category` string
- `definition` string

**CivicsQuestion**
- `question`* string, `answer`* string
- `version` enum `2008 | 2025` (default `2008`)
- `category` string (matched against `Lesson.topic`)
- `difficulty` enum `easy | medium | hard` (default `medium`)

**InterviewQuestion** — N-400 interview practice
- `section`* enum `small_talk | personal_info | morals_ethics | oath_requirements`
- `question`* string, `expected_response`* string
- `response_type` enum `open_ended | yes_no | specific_answer` (default `specific_answer`)
- `order` number, `tips` string

**Lesson**
- `topic`* enum `Principles of American Democracy | System of Government | Rights and Responsibilities | U.S. History | Geography and Symbols`
- `title`* string, `content`* string, `description` string
- `video_url` string (YouTube)
- `key_points` array of `{ text*, definition?, image_url? }`
- `order` number

**LessonFlashcard**
- `lesson_id`* string, `term`* string, `definition`* string, `example` string

**LessonQuiz**
- `lesson_id`* string, `question`* string, `options`* string[], `correct_answer`* string,
  `explanation` string
- Note: only *written* (by `GenerateLessonsButton`); `LessonDetail` builds its quiz from
  `CivicsQuestion` filtered by `category = lesson.topic` instead.

### Users & profiles

**User** (Base44 built-in; these are the custom extensions — `email`, `full_name`,
`role` come from the platform)
- `display_name`* string
- `points` number (default 0)
- `badges` string[] (default `[]`)
- `max_streak` number (default 0)
- `test_date`* date-time

**PublicProfile** — publicly readable mirror of a user
- `user_email`* string, `display_name`* string
- `points` number (default 0), `badges_count` number (default 0)
- `invite_code` string (tutor class join code)
- `account_type` enum `student | tutor` (default `student`)
- `zip_code` string, `street_address` string
- `representative_data` object (cached representative lookup)

### Progress & activity

**UserProgress** — per-user, per-item practice state (SM-2 SRS)
- `user_email`* string, `content_id`* string
- `content_type` enum `sentence | vocabulary | civics_question` (default `sentence`)
- `status` enum `practicing | mastered` (default `practicing`)
- `last_practiced` date-time
- `assignment_id` string
- `ease_factor` number (default 2.5), `interval` number days (default 0),
  `consecutive_correct` number (default 0)
- `last_result` enum `correct | incorrect`
- `best_score`, `last_score` number 0–100 (default 0), `total_attempts` number (default 0)

**LessonProgress**
- `user_email`* string, `lesson_id`* string, `topic`* string
- `completed` boolean (default false)
- `quiz_attempts`, `best_score`, `last_score`, `total_questions` number (default 0)
- `last_attempt_date` date-time
- `needs_review` boolean (default false)

**LessonNotes**
- `user_email`* string, `lesson_id`* string, `content`* string (rich-text HTML)
- `lesson_title` string, `lesson_topic` string

**AIStudyLog** — Study Buddy Q&A history
- `user_email`* string, `question`* string, `answer`* string
- `language` string (default `en`), `created_at` date-time

### Tutoring & communication

**TutorRelationship**
- `tutor_email`* string, `student_email`* string
- `status` enum `pending | active | rejected` (default `pending`)
- `created_by` string (email of whoever initiated)

**Assignment**
- `tutor_email`* string, `student_email`* string
- `content_type`* enum `sentence | vocabulary | civics_question | custom`
- `content_id` string
- `custom_content` string (legacy), `custom_type` enum `sentence | vocabulary | civics_question`,
  `custom_data` object (e.g. `{word, definition}`, `{question, answer}`)
- `status` enum `pending | completed` (default `pending`)
- `assigned_date`, `completed_date`, `feedback_date` date-time
- `tutor_feedback` string

**Message**
- `sender_email`* string, `receiver_email`* string, `content`* string
- `read` boolean (default false)

**Notification**
- `user_email`* string, `title`* string, `message`* string
- `type` enum `request | assignment | message | system | alert` (default `system`)
- `link` string (relative URL), `read` boolean (default false)

## Base44 SDK usage

### Client setup
- `api/base44Client.js` — the single `createClient({ appId, serverUrl, token,
  functionsVersion, requiresAuth: false })`, exported as `base44`. Everything imports
  this.
- `api/entities.js` — exports `Query` (`base44.entities.Query`) and `User`
  (`base44.auth`). **Unused** by the app.
- `api/integrations.js` — re-exports `Core`, `InvokeLLM`, `SendEmail`, `SendSMS`,
  `UploadFile`, `GenerateImage`, `ExtractDataFromUploadedFile`. **Unused** — callers go
  through `base44.integrations.Core.*` directly.
- `lib/AuthContext.jsx` — imports internal `createAxiosClient` from
  `@base44/sdk/dist/utils/axios-client` (deep import; may break on SDK upgrades).
- `lib/app-params.js` — supplies client params; no SDK import.

### Non-SDK calls to the Base44 backend
- `OAuthConsent.jsx` — raw `fetch` to `/api/apps/:appId/mcp/consent-info` and
  `/api/apps/:appId/mcp/authorize-grant` (MCP OAuth consent; references a
  `base44/mcp/config.json` that is not in this repo).
- `lib/AuthContext.jsx` — public-settings request via the SDK's internal axios client.
- Static images are hosted on `media.base44.com` (`index.html`, `Home.jsx`,
  `Layout.jsx`, `components/practice/VirtualInterviewer.jsx`).

Other external call: `components/civics/RepresentativeFinder.jsx` fetches Wikipedia's
REST summary API for official photos.
